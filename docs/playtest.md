# Playtest checklist

One full run, 1815 to 1850, played by a person. A script can measure balance; only a person can judge feel and time. Fill this in as you play and send it back, or paste your notes into chat.

## Before you start

- [ ] `npm run dev`, open http://localhost:5173
- [ ] Note the seed shown on the start screen: ________
- [ ] Note the start time: ________
- [ ] Play with a trackpad only (CLAUDE.md's UI rule)

## Playing

Play as you like. Don't try to break the game, and don't read the code or the balance report first.

At **1825 Q3** (the London crisis warning), stop for a moment and note:

- [ ] Did you see the warning coming? Where did you first notice it?
- [ ] Did you know what to do about it?

At the **first succession** (when the head dies), note:

- [ ] Was your heir ready? Did you know they needed training?

## After the run

**Time**

- Finish time: ________, total ________ minutes (the spec aims for 60 to 90)
- Did any stretch feel too long? Which years?

**Outcome**

- Final net worth: ________ fl. Bankrupt? ____ If so, in what year and why?
- Did the chronicle at the end match how the run felt?
